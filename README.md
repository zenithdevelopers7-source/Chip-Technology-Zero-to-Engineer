# Chip Technology — Zero to Engineer

A daily practical journey from zero semiconductor knowledge
to digital electronics, computer architecture, and AI chip design.

## Objective

Learn how semiconductor chips work and progressively develop
the skills required to design and simulate digital hardware.

## Learning Roadmap

| Month | Topic |
|---|---|
| 1 | Chip Technology Fundamentals |
| 2 | Digital Electronics |
| 3 | Verilog Programming |
| 4 | Computer Architecture and RISC-V |
| 5 | AI Chip Fundamentals |
| 6 | First AI Accelerator Prototype |

## Daily Workflow

1. Study one concept.
2. Write learning notes.
3. Complete a practical exercise.
4. Test the implementation.
5. Commit the results to GitHub.
