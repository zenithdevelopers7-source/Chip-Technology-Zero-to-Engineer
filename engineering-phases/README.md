## Using the reference library

1. Select a phase and click a topic.
2. Read its diagram from **input → engineering method → output**.
3. Complete the proposed practical activity using appropriate software, simulation, or supervised laboratory facilities.
4. Check and document the outcome. Only then add experimental artifacts to the topic folder.

**Safety and feasibility:** Fabrication steps, high-voltage electronics, lasers, chemicals, and lab processing require suitable trained facilities; the diagrams are conceptual, not instructions for performing hazardous procedures. For future research topics, compare evidence, readiness and limitations rather than assuming a technology is proven.
